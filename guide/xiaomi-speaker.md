# 小爱音箱输出

开发版功能，支持小爱音箱 Play **L05B** 和曲库 MP3。开启一个开关后，继续使用网页原有队列、播放和音量控件。本机仍运行同一音频流提供进度与歌词，但保持静音，仅音箱发声；允许时间差。参考固件为 **1.68.2**，其它型号、格式或固件尚未验证。

## 连接与播放

1. 小米音箱插件默认未安装。管理员先在「设置 → 站点管理 → 插件 → 小米音箱」中显式安装；然后每位用户在「设置 → 个人设置分组的插件 → 小米音箱 → 账号连接」中查看授权说明并连接本人小米账号。
2. 使用绑定音箱的小米账号扫码，并在手机上确认。二维码约五分钟有效；连接失败时可先「重试检查授权」，过期后重新生成。
3. 在播放器更多菜单或歌曲菜单打开「音箱输出」，选择 L05B，打开「启用音箱输出」。未播放时不会自行开播；已播放时会发送当前歌曲。
4. 正常选歌、上下首、暂停/继续、编辑队列。网页负责选择下一首，音箱跟随；本版只接受 MP3，不提供转码。
5. 音量保持原单滑杆外观，滑杆、静音、滚轮和快捷键都控制当前输出；开启时调音箱，关闭时调本机。本机原音量值保留，不能在音箱模式下额外调响本机。
6. 关闭「启用音箱输出」先停止本次音箱播放，再恢复本机原静音状态，原流继续。停止不确定时保持本机静音；外部接管或失去授权而无法确认停止时，先暂停本机，避免突然多处出声。页面刷新不会自动开启音箱输出。

网页进度不代表音箱的精确进度。拖动或点击歌词会发送定位请求；没有设备位置确认时会明确提示。命令回执不能证明出声；「下发状态不确定」时先检查音箱，避免重复播放。发现其他来源接管音箱后自动投放暂停，重新关闭/开启前先确认当前用途。关闭页面后当前单曲可继续，队列自动续播需要网页运行；系统冻结后台标签时不保证续播。

## 授权与私有音频

管理员卸载插件会关闭小米接口和媒体新请求，并保留各用户的加密绑定。重新安装后可继续使用绑定，但旧媒体链接不会恢复；音箱已缓冲的片段无法收回。卸载时网页先暂停本机流，再退出音箱输出。

每个 FlareTune 用户管理自己的小米连接。账号服务令牌在后端用 `SETUP_SECRET` 的独立派生密钥加密保存，网页不接收令牌或 Cookie；扫码临时材料同样加密并限时使用。授权失效或密钥轮换后需重新扫码。无需增加另一台常开的电脑、NAS 或新 Cloudflare 服务。

小米服务会收到当前歌曲的临时媒体链接。任何持有该链接的主体在有效期内都可能读取该曲；链接与设备控制关联不等于验证请求来自物理音箱。不要分享该 URL，也不要在自定义代理、分析或访问日志中记录完整查询参数。标准开发配置隐藏查询字符串，生产配置关闭原始请求日志。

链接只允许指定歌曲的 GET/HEAD/Range，最长一天，至少预留歌曲时长和十五分钟缓冲，并受签发网页登录会话约束。剩余登录有效期不足时需重新登录；缺失/异常歌曲时长不保证播放。换歌、停止、解绑、注销、会话失效或账号停用后，后续请求被拒绝；已经传给设备或缓冲的音频无法收回。失效连接也可以在管理中解绑清除已保存授权。

私有 R2 桶及原 `/media/` 网页鉴权保持。实例需有音箱所在网络可访问的 HTTPS 地址和有效证书；本机 localhost 地址无法作为音箱音频入口。公开 Demo 不连接小米账号或发送控制命令。

默认使用当前实例域名生成媒体链接。部署者可用 `SPEAKER_MEDIA_ORIGIN` 指定同一个 Worker 的另一个 HTTPS 域名，例如 `https://music.example.com`，以单独验证设备网络的可达性。只填来源，不含路径、查询参数或账号密码；域名必须绑定到同一个 Worker，保持 `/speaker-media/*` 优先进入 Worker 及查询参数日志脱敏。配置不提供外部音频代理或重定向。

## 当前验证边界

扫码、凭据隔离、媒体授权/撤销、Range 及不确定回执有本地自动检查和独立审查。开发版使用同 Worker 的自定义媒体域名后，私有单曲、离开网页继续播放、暂停、恢复和拖回先前段落均由用户确认；已有进度起播改为普通播放后单独定位，也已确认出声。音量可独立修改并低频读回。原 workers.dev 媒体入口未成功的具体网络原因仍未确定。设备状态可能缺少身份/进度，MiNA code100按未知处理，不代表真实位置或连接失败；网络故障和命令不确定仍须人工检查，不自动重发。验证仅覆盖当前L05B/参考固件，不保证所有环境。使用的是社区研究的 MiNA 接口，服务变更可能要求重新连接或适配。手机端自定义歌名/封面、真实进度展示和反向暂停/恢复/定位仅完成研究，未实现；音箱音量可以低频读回。暂不提供云端后台队列、多房间同步或语音点歌。
