# 管理与维护

[简体中文](administration.md) · [English](administration.en.md)

## 现有管理入口

管理员登录后可在设置侧边栏进入「曲库管理」「歌曲入库」「AI 与助手」「账号管理」「实例设置」。实例设置集中展示实例名称、访问来源、入库设备、运行状态与数据库升级。普通成员不能访问这些管理分类。音乐文件由实例管理员自行导入；媒体通过 Worker 读取私有 R2，并按会话权限访问。

「实例设置」显示应用版本、实例状态、基础结构版本和逐项功能迁移。有待更新项时，管理员可以启动内置兼容升级；全部完成后显示已是最新。旧的 `/settings/admin/instance` 地址会转入实例设置。

## AI 接入配置

在「AI 与助手」的「供应商配置」点击「添加供应商」，选择 DeepSeek、OpenAI、Anthropic、Gemini 或自定义接入方案，填写 API Key 和显示名称（可留空使用默认名称）。页面只显示已添加项；同种方案可添加多份，例如两个不同名称和 Key 的 DeepSeek。官方连接分别使用 Chat Completions、Responses、Anthropic Messages、Gemini 原生协议，协议和地址由系统提供，不显示模型或高级接入字段。编辑时可改显示名称、更新或留空保留 Key；接入方案保存后不切换，改用其他方案时新增连接。

三方代理添加「自定义供应商」，填写名称、四种协议之一、HTTPS API 基础地址（含版本前缀，不含最终请求路径）和 Key。只有自定义显示协议和地址。只向信任的公开服务填写地址，不支持本机或内网地址。

下方「功能使用方案」分别为音乐助手和歌词 AI 选择供应商，点击「获取模型」后直接选择，也可手填模型 ID，再按实际能力勾选「此模型支持视觉」并保存。二者可共用同一供应商而使用不同模型；切换供应商或模型需重新确认视觉，获取列表不代表能力验证。更换自定义协议或地址须重新输入 Key，同时重置引用功能的视觉声明和生成参数；旧连接保留原协议和目的地，非标准地址显示为自定义，不合并旧 Key。现有实例先在「实例设置」应用补充迁移（0009 AI 协议、0010 用户图片、0011 功能模型）；迁移前旧配置和文本功能仍可使用。Key 加密保存，不会返回浏览器。

### 用户图片与助手图片输入

个人设置可上传、更换和移除本人头像；自建普通个人歌单详情可设置封面，固定收藏红星和共享专辑不受影响。选择 JPEG、PNG 或 WebP（每图 5 MiB、最多 2000 万像素）后，头像/封面提供 1:1 裁剪、拖动、缩放及键盘位置滑杆，分别保存 512/1024 方形静态 WebP，不保留额外原图。

在「AI 与助手」启用默认关闭的「允许助手图片输入」，并在音乐助手的功能模型配置中依据真实能力勾选「此模型支持视觉」。旧部署配置不自动视为视觉模型。助手单条消息最多 4 图，等比缩至最长边 2048；最近 24 条消息最新最多 4 图可供连续追问，超出时提示重新附图。重复发送历史图会产生供应商的图片输入消耗；关闭开关或改用非视觉模型后不会再发新图或历史图，文本仍可用，原历史图片仅本人可看。头像和歌单封面不会自动发给模型。

私人 R2 使用 `users/<内部账号ID>/avatars/`、`playlist-covers/`、`chat-images/` 随机对象键，数据库保存归属、用途和引用。`users/` 是保留的私人前缀，不可将共享 `MEDIA_PREFIX` 配为 `users` 或其子目录，也不要为桶打开公开读取。图片读取仍需正常本人会话，管理员也不能读取他人图。未使用草稿 24 小时后及失败删除的墓碑在后续本人图片写入中最多处理 10 项；替换成功后精确清理无引用旧图，失败保留旧引用。D1 与 R2 均须备份。

## 曲库增删

管理员在网页后台「歌曲入库」的「选歌」视图选择浏览器文件，或从已连接的[本地入库设备](../tooling/ingest-agent/README.md)目录选歌；加入后自动切换到「入库清单」，可随时返回选歌而不丢失清单。两种来源共用编辑、查重和保存流程。设备歌曲以分页卡片显示元数据，默认不读取原始封面；扫描大量歌曲后可以先筛选、按目录映射语言并勾选需要入库的部分。目录映射可选择按目录名、按标签和文字自动判断，或指定语言；只影响随后加入清单的歌曲，清单仍可逐首修改。发现相似条目时，可核对后决定跳过、新增或替换；替换前页面会检查目标曲目是否已被其他操作修改。批量入库中点击「暂停入库」会等待当前歌曲处理完成再停止，随后「继续入库」只处理尚未开始的剩余歌曲；失败项仍可单独重试。

当前网页曲库管理的删除按钮要求确认；歌曲仍被歌单、播放记录或歌词数据引用时会拒绝删除。成功时只删除歌曲元数据，音频和封面文件保留。网页没有删除引用或清理媒体的勾选项。旧手动本地网页工具另有影响预览与确认清理流程，不属于入库设备程序；不要按该旧流程理解当前网页按钮。

## 数据库升级

| 实例状态 | 操作 |
| --- | --- |
| 已知且兼容的旧 schema，管理员仍可登录 | 在「实例设置」查看当前与目标版本，启动内置升级。 |
| 已知旧版，需要暂停业务 | 进入维护页，部署者验证 `SETUP_SECRET` 后分批继续升级；维护期间不能登录。 |
| 未知版本、账本不一致或结构损坏 | 保持业务关闭，部署者依据备份在应用外诊断；不自动修复。 |

升级接口只接受当前 Worker 内置、按序执行的 migration，不提供任意 SQL 执行或 schema 降级。检测到旧共享歌单数据时，普通管理员入口会要求先备份 D1；确认备份后使用维护页的初始化密钥继续。升级期间业务接口保持关闭，页面提示每批进度。重大升级前应有数据库备份及恢复方案。

## 凭据与数据

- `SETUP_SECRET` 用于首次认领、已知维护态升级和已保存 AI 模型密钥的加密根材料；不能重置管理员。
- AI 提供商密钥由管理员按需配置，不是首次部署必填项。
- D1 保存账号、会话、个人音乐数据和实例配置；R2 存储音频、封面和生成的媒体材料。部署者负责自己音乐与封面的使用权及备份。
