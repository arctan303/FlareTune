# 管理与维护

## 现有管理入口

管理员登录后可在设置侧边栏进入「实例与访问」「AI 与助手」「曲库」「账号」「系统状态」。普通成员不能访问这些管理分类。音乐文件由实例管理员自行导入；媒体通过 Worker 读取私有 R2，并按会话权限访问。

「系统状态」显示应用版本、实例状态、数据库当前版本和目标版本。有可执行的旧版迁移时，管理员可以启动升级；当前版本一致时显示“数据库已是当前版本”。

## 数据库升级

| 实例状态 | 操作 |
| --- | --- |
| 已知且兼容的旧 schema，管理员仍可登录 | 在「系统状态」查看当前与目标版本，启动内置升级。 |
| 已知旧版，需要暂停业务 | 进入维护页，部署者验证 `SETUP_SECRET` 后分批继续升级；维护期间不能登录。 |
| 未知版本、账本不一致或结构损坏 | 保持业务关闭，部署者依据备份在应用外诊断；不自动修复。 |

升级接口只接受当前 Worker 内置、按序执行的 migration，不提供任意 SQL 执行或 schema 降级。检测到旧共享歌单数据时，普通管理员入口会要求先备份 D1；确认备份后使用维护页的初始化密钥继续。升级期间业务接口保持关闭，页面提示每批进度。重大升级前应有数据库备份及恢复方案。

## 凭据与数据

- `SETUP_SECRET` 用于首次认领、已知维护态升级和已保存 AI 模型密钥的加密根材料；不能重置管理员。
- AI 提供商密钥由管理员按需配置，不是首次部署必填项。
- D1 保存账号、会话、个人音乐数据和实例配置；R2 存储音频、封面和生成的媒体材料。部署者负责自己音乐与封面的使用权及备份。
