# 在线 Demo

[简体中文](demo.md) · [English](demo.en.md)

Demo 使用与正式实例相同的播放器和曲库界面，免登录体验公开授权音乐。[打开在线 Demo](https://flaretune-demo.arctan.workers.dev)。

| 可操作 | 范围 |
| --- | --- |
| 播放、队列、进度、全屏、歌词 | 真实静态媒体；预置人工逐行时间轴，无联网取词 |
| 搜索、语言分类、每日推荐、漫游 | 在浏览器查询静态曲库；没有的语种显示空态 |
| 收藏、个人歌单、历史、常听 | 当前浏览器保存；初始收藏/历史为空，示例歌单明确标识 |
| 外观与九种界面语言 | 当前浏览器保存，可切换和恢复 |
| AI、管理、入库、账号和连接 | 只读案例；不调用模型、不上传文件、不创建服务器账号 |

同一浏览器配置的多个标签页共享数据，其他浏览器/设备不共享。清除站点数据或关闭无痕环境后可能丢失；存储不可用时只保留临时体验。顶部「重置演示数据」只清除 Demo 自身状态。不要把 Demo 当作音乐或歌单备份。

这是独立的 Static Assets 部署，没有业务 Worker 脚本、D1、R2、模型密钥或访客数据库。页面、词典、封面和音频通过网络下发，个人状态不发送到服务器。正常自建实例仍需登录，音乐保存在部署者的私有 R2。


当前静态托管对音频 Range 请求返回完整文件。已下载/缓冲的音频可拖动，慢速网络可能需要等待更多缓冲；Demo 不声称支持 206 字节分段流。未知资源地址可能返回 SPA 页面，播放器会处理媒体失败并尝试下一首可用歌曲。

## 素材与许可

曲库含 Kevin MacLeod 的 CC BY 4.0 作品及 Rocks From The Garden 的《Amazing Grace》录音（作者公开领域贡献）。逐曲来源、许可、署名、加工记录和校验值见 [catalog.json](../demo/catalog.json)，页面顶部也可查看。封面为项目原创几何图；公共领域歌词使用人工逐行时间轴，不声称逐字精度。MIT 不覆盖第三方音乐。

## 本地复现与独立部署

在仓库根目录使用受支持的 Node.js 安装锁定依赖，然后执行：

```sh
npm ci
npm run demo:media
npm run demo:dev
```

音频体积较大，不纳入 Git；media 命令从清单原始来源下载，build 命令检查 SHA-256，缺文件/不匹配会停止。构建为 `npm run demo:build`，输出 `dist-demo/`。若要在自己的账号真实部署，先审阅 `demo/wrangler.toml`，使用独立名称，再执行 `npm run demo:deploy`。此命令是远程部署，会创建/更新该 Demo Worker；普通 `npm run build` 继续构建正常实例。
