# 在线 Demo

[简体中文](demo.md) · [English](demo.en.md)

Demo 使用与正式实例相同的播放器和曲库界面，免登录体验公开授权音乐。[打开在线 Demo](https://flaretune.arcinks.com)。

| 可操作 | 范围 |
| --- | --- |
| 播放、队列、全屏、歌词 | 真实静态媒体；预置人工逐行时间轴，无联网取词 |
| 进度拖动 | 音频支持 206 字节范围响应，可拖动跳转播放位置 |
| 搜索、语言分类、每日推荐、漫游 | 在浏览器查询静态曲库；没有的语种显示空态 |
| 收藏、个人歌单、历史、常听 | 当前浏览器保存；初始收藏/历史为空，示例歌单明确标识 |
| 外观与五种界面语言 | 当前浏览器保存，可切换和恢复 |
| 助手对话 | 可正常发送消息、刷新恢复及清空；回复是明确标识的固定示例，不调用模型；仅在本浏览器保留最近 30 轮对话 |
| 管理、入库、账号和连接 | 默认模拟管理员，复用正式页面及完整设置弹窗；预置公开示例配置可查看，不上传文件、不修改服务器配置、不创建服务器账号 |

同一域名下、同一浏览器配置的多个标签页共享数据，其他浏览器/设备不共享。旧 workers.dev 地址与公开域名属于不同站点，浏览器数据不会自动迁移。清除站点数据或关闭无痕环境后可能丢失；存储不可用时只保留临时体验。个人设置末尾的「重置演示数据」只清除 Demo 自身状态。不要把 Demo 当作音乐或歌单备份。

这是独立的 Static Assets 部署，只有音频请求经过一个只读媒体 Worker，以提供正确的 Range 响应；其他界面、偏好、收藏、歌单和助手示例在浏览器处理。没有 D1、R2、模型密钥或访客数据库。页面、词典、封面和音频通过网络下发，个人状态不发送到服务器。正常自建实例仍需登录，音乐保存在部署者的私有 R2。


媒体 Worker 只读取清单内打包的音频，支持 GET、HEAD、单段字节范围和越界 416，不提供上传、代理任意地址或业务接口。音频请求计入 Worker 请求用量；其余静态资源按 Static Assets 规则下发。播放器仍受浏览器音频格式和网络条件限制。

## 素材与许可

曲库含 Kevin MacLeod 的 CC BY 4.0 作品及 Rocks From The Garden 的《Amazing Grace》录音（作者公开领域贡献）。逐曲来源、许可、署名、加工记录和校验值见 [catalog.json](../demo/catalog.json)，也可在个人设置末尾查看。封面为项目原创几何图；公共领域歌词使用人工逐行时间轴，不声称逐字精度。MIT 不覆盖第三方音乐。

## 本地复现与独立部署

在仓库根目录使用受支持的 Node.js 安装锁定依赖，然后执行：

```sh
npm ci
npm run demo:media
npm run demo:dev
```

音频体积较大，不纳入 Git；media 命令从清单原始来源下载，build 命令检查 SHA-256，缺文件/不匹配会停止。构建为 `npm run demo:build`，输出 `dist-demo/`。若要在自己的账号真实部署，先审阅 `demo/wrangler.toml`，使用独立名称，将 `routes` 替换为自己的域名或删除该段使用 workers.dev，再执行 `npm run demo:deploy`。此命令是远程部署，会创建/更新该 Demo Worker；普通 `npm run build` 继续构建正常实例。
