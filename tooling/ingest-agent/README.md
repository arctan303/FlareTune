# 本地入库设备使用指南

[简体中文](README.md) · [English](README.en.md)

本工具在存放音乐的电脑上读取音频文件，并主动连接你的 FlareTune 实例。管理员在播放器网页后台选择目录歌曲；浏览器文件和设备歌曲进入同一入库清单，共用编辑、查重和保存流程。运行工具的电脑与操作网页的电脑可以不同，也不需要开放公网入站端口。

## 准备

- 在存放音乐的设备上安装 Node.js 22.12.0 或更新版本，并取得与播放器实例兼容的 FlareTune 项目代码。设备入库接口从 FlareTune 1.1.0 开始提供。
- 准备该实例的管理员账号，以及设备上可读取的一个或多个音乐目录。设备需要能主动访问实例地址；网页操作端只需要能访问播放器后台。
- 在仓库根目录安装依赖。首次使用建议运行 `npm ci`；Windows PowerShell 可将下文的 `npm` 写作 `npm.cmd`。

## 首次配置

```sh
npm ci
npm run ingest:configure
```

按终端提示填写设备名称、实例根地址、管理员用户名与密码、音乐目录。目录须为这台设备上的绝对路径，支持 1～16 个；多个目录用半角分号 `;` 分隔，例如 Windows 的 `D:\music;E:\albums` 或 macOS／Linux 的 `/home/me/music;/mnt/albums`。配置命令会先验证目录和管理员登录，成功后保存配置；以后不必每次输入。

密码直接保存在该设备的用户配置文件中，请只在自己信任的设备上运行。配置文件不进入项目仓库，位置为：

| 系统 | 配置文件 |
| --- | --- |
| Windows | `%APPDATA%\FlareTune\ingest-agent.json` |
| macOS | `~/Library/Application Support/FlareTune/ingest-agent.json` |
| Linux | `${XDG_CONFIG_HOME:-~/.config}/flaretune/ingest-agent.json` |

要修改设备名称、实例、账号或目录，重新运行 `npm run ingest:configure`；会沿用这台设备的身份。管理员密码变更后也需要重新配置。

## 启动并在后台选歌

```sh
npm run ingest
```

保持终端运行。程序会登录实例、扫描已配置目录并报告连接状态；它不启动独立网页，也不监听本机端口。可在同一实例上运行多台设备，每台设备分别配置。

1. 用管理员账号进入播放器的「设置 → 系统管理」，在“入库设备”查看设备是否在线及上次扫描时间。
2. 进入「设置 → 歌曲入库 → 选歌 → 已连接设备目录」，选择设备。可刷新设备列表，或点击「重新扫描」读取目录的新变化。
3. 按歌名、歌手、专辑或路径筛选，也可只看某个目录；勾选单首或当前筛选结果，再点击「将所选歌曲加入清单」。扫描出很多歌曲时无需把所有歌曲都加入清单。
4. 在「入库清单」核对标题、专辑、封面与语言，必要时逐首编辑。相似歌曲可查看匹配详情并选择跳过、新增或替换；确认后入库。批量处理可在当前歌曲结束后暂停，再继续剩余歌曲；失败项可以单独重试。

仅扫描、筛选、勾选和加入预览清单不会上传音频；实际入库时才由设备读取和传输文件。设备目录卡片默认不读取全部原始封面，需要时可在预览中查看单首。

### 文件夹语言映射

把歌曲放在 `zh`、`en`、`jp`／`ja`／`jn`、`ko`、`yue`、`纯音乐`／`instrumental` 子目录时，页面可把目录名作为语言建议。每个目录也可改为“按标签和文字判断”或指定某种语言。映射只影响随后加入清单的歌曲；清单内仍可逐首修改，自动判断需要人工核对。

## 限制与常见问题

- 当前通过管理员媒体接口传输音频，单文件上限为 100 MB，上传任务依次执行；设备工具尚不支持 R2 直传。大量歌曲建议先筛选，再分批处理。
- 设备离线时后台仍会显示上次扫描信息，但不能继续从该设备选歌或重新扫描。先确认终端仍在运行、设备能访问实例、实例版本包含设备入库接口，并核对管理员账号；重新上线后可点击「重新扫描」。更改本地文件或遇到旧文件引用失效时也应重新扫描。
- 暂时出现 `fetch failed` 时，任务轮询每 10 秒重试，通常无需重新配置或重新扫描。日志会尽量附上 `ECONNRESET`、连接超时等底层错误码；持续失败时核对设备到实例的网络或代理。
- 上传连接中断后，工具会用原媒体 ID 复核并重试，避免因一次断线生成另一份媒体；若单首任务最终失败，可在后台查看错误后重试。
- 更新工具代码后停止旧进程，再运行 `npm run ingest`；已有配置可继续使用。要停止设备程序，在终端按 `Ctrl+C`。
